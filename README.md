## What the prototype demonstrates

- Messy versus contextualized workforce data
- A live-computed Top-40 decision overlap
- False positives removed and newly surfaced employees
- Confidence-aware reskilling recommendations
- Human-review routing
- Employee-level evidence and next actions

## Data summary

- 200 canonical employees
- 220 source-like records in the messy dataset
- 94 of 200 primary records have blank skill fields (47%)
- 20 duplicate-ish records
- Normalized titles, inferred skills, confidence scores, and human-review flags in the clean dataset

## Files

- `index.html` — standalone browser prototype
- `medika_messy.csv` / `.json` — enterprise reality dataset
- `medika_clean.csv` / `.json` — post-contextualization dataset
- `docs/Rakamin_Product_Manager_Case_Study.pdf` — written submission

## GitHub Pages setup

1. Create a public repository named `rakamin-workforce-decision-studio`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Open the live URL shown by GitHub Pages.
